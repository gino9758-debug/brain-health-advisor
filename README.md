# 脑健康家庭顾问

面向全家的脑健康建议 Skill——「脑营养是燃料，脑训练是发动机」（Brain Health Advisor）

## 项目解决什么问题

"吃什么补脑""怎么让孩子更聪明""老人记性差怎么办"——市面上补剂与"脑力提升"宣传鱼龙混杂。本技能坚持"脑训练优先、营养辅助"，对有商业代言背景的专家/产品做辩证评估，并按家庭成员角色分层给建议。

## 核心原则

1. **燃料与发动机**：脑营养是燃料，脑训练是发动机。发动机不转，燃料堆再多也没用
2. **辩证评估**：对有商业代言（补剂、保健品等）的专家/作者，其推荐方向需打折扣看待
3. **分层建议**：孩子/成人/老人的脑健康策略重心不同，不可一概而论

## 主要功能

| 能力 | 说明 |
|------|------|
| 场景识别 | 孩子学习升学 / 成人自我提升 / 老人认知健康 / 补剂保健品评估 / 脑科学书籍观点 |
| 分层建议 | 按家庭成员角色给出脑训练方法与营养建议（references/family-guide） |
| 辩证提醒 | 识别专家/作者/品牌的商业利益关联与证据强度（references/critical-thinking） |
| 输出结构 | 核心原则提醒 → 分层建议 → 辩证评估 → 行动建议 |
| 边界处理 | 多角色分别分析、用户拒绝框架时尊重并简提、不直接推荐品牌、医学诊断类引导就医 |

## 安装方法

将本目录放入你的 Agent 技能目录（如 `~/.codex/skills/`、`~/.claude/skills/`），重启会话后生效。

### 要求
- 无第三方依赖

## 使用方法

触发场景：孩子学习方法/备考/注意力训练、老人认知健康/记忆衰退/阿尔茨海默预防、成人自我提升/脑力训练、DHA/卵磷脂等补脑产品咨询、"吃什么补脑""怎么变聪明""怎么增强记忆"等提问。

## 输入输出示例

**输入：** 孩子上小学，想买 DHA 补脑，推荐什么牌子
**输出：** 核心原则（先学习方法/睡眠/运动）+ 孩子分层建议（主动回忆/间隔复习/食补 Omega-3）+ 不直接推荐品牌的辩证提醒 + 行动建议

**输入：** 老人记性变差，银杏提取物能预防痴呆吗
**输出：** 证据强度评估（单一补剂证据有限）+ 老人分层建议（认知刺激/社交/运动/慢病管理）+ 先体检排除可逆因素的行动建议
